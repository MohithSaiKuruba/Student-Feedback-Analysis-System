# Student Feedback Analysis System

A beginner-friendly B.Tech project built with **Python, Flask, MySQL, Pandas, NumPy and Matplotlib**. It collects anonymous course feedback, validates ratings from 1 to 5, and presents aggregate summaries and charts.

## Features

- Anonymous feedback form (no student name, email or ID field).
- Course and question lists, plus API endpoints to add them.
- Server-side validation and database error handling.
- Average rating and response-count reports by course and question.
- Rating distribution and aggregate CSV export.
- Three chart types generated by `analysis.py`.
- Small-group suppression controlled by `MIN_GROUP_SIZE` (default 5).
- Comments are optional and are not displayed in reports or included in exports.

## Requirements

- Python 3.10 or newer
- MySQL 8.x (or compatible version)
- pip

## Run locally

1. Clone or download this repository.
2. Create and activate a virtual environment:

   **Windows**
   ```powershell
   py -m venv .venv
   .venv\Scripts\activate
   ```

   **macOS/Linux**
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```

3. Install packages:

   ```bash
   pip install -r requirements.txt
   ```

4. Open MySQL Workbench or the MySQL command line and run `schema.sql`. The script creates the `feedback_system` database, tables, example courses and questions.
5. Copy `.env.example` to `.env`, then set your local MySQL password and user. Never commit the real `.env` file.
6. Start the app:

   ```bash
   python app.py
   ```

7. Open http://127.0.0.1:5000 in your browser. Check http://127.0.0.1:5000/health for database status.

## Generate analysis and charts

After enough feedback has been collected, run:

```bash
python analysis.py
```

Aggregate CSVs and charts are written to the local `reports/` folder. This folder is ignored by Git. Charts are created only when the privacy threshold is met. If the database has no feedback yet, the script prints a helpful message.

## API reference

All JSON request bodies use `Content-Type: application/json`.

| Method | Endpoint | Purpose |
|---|---|---|
| GET | `/health` | App/database health |
| GET | `/api/courses` | List courses |
| POST | `/api/courses` | Add a course: `{"course_name":"Java Programming"}` |
| GET | `/api/questions` | List feedback questions |
| POST | `/api/questions` | Add a question: `{"question_text":"Materials are useful"}` |
| POST | `/api/feedback` | Submit feedback: `{"course_id":1,"question_id":1,"rating":4,"comment":"Clear explanations"}` |
| GET | `/api/reports/courses` | Average rating and response count by course |
| GET | `/api/reports/questions` | Average rating and response count by question |
| GET | `/api/reports/distribution` | Number of responses per rating |
| GET | `/api/reports/export` | Download aggregate CSV |

Successful feedback submission returns HTTP 201. Invalid fields return HTTP 400; missing course/question returns HTTP 404; duplicate course/question returns HTTP 409; unavailable database returns HTTP 503.

## Testing checklist

Before your review/demo, check:
- Rating values 1 and 5 are accepted; 0, 6, missing and non-numeric values are rejected.
- Empty comments work; comments over 1,000 characters are rejected.
- Invalid/missing course and question IDs are rejected.
- Duplicate course and question names are handled.
- Empty database reports work and hide small groups.
- Stop MySQL and confirm the app returns a useful error instead of crashing.
- CSV exports contain only aggregated values and no individual comments.

## Privacy and limitations

- The form does not collect student identifiers. Do not put names or personal details in comments.
- Aggregates below `MIN_GROUP_SIZE` are suppressed in reports by default. Choose a threshold appropriate for your institution.
- This is an educational prototype; configure production-grade authentication, HTTPS, database permissions, backups and deployment secrets before real institutional use.
- Ratings summarize submitted responses and may be biased by who chooses to respond. They are not proof of teaching quality.
- The app does not claim to perform sentiment analysis. Comments are intentionally excluded from public reports.
